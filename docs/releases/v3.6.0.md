# NodeChain v3.6.0 — First Public-Era Release

## Release summary

NodeChain v3.6.0 is the first release produced entirely from the clean
public canonical history at `github.com/Alajmah/NodeChain`.

This release introduces flat-result provenance versioning, establishes
the public development governance model, and hardens the hosted CI
pipeline with blocking lint, twelve required checks, and Node 24
GitHub Actions runtime.

## What is new

### Flat-result provenance versioning v1

Explicit versioned provenance contract for search-result payloads:

- Current version (1) with complete provenance fields
- Legacy version (0) compatibility path
- Pre-version record compatibility
- Strict RFC 3339 timestamp validation (calendar, clock, and offset ranges)
- Unknown and malformed versions fail closed

### Public development governance

- Solo-maintainer operating policy (zero required approvals)
- Release checklist with artifact proof requirements
- Emergency admin bypass procedure with evidence retention

### CI hardening

- Blocking Ruff undefined-name gate (E9, F63, F7, F82)
- Sixteen F821 baseline findings eliminated
- Twelve required hosted checks enforced by branch protection
- Node 24 GitHub Actions runtime (checkout v7.0.1, setup-python v7.0.0)
- Windows test timeout of 90 minutes

## Public operating model

## Known boundaries

- Windows hosted-runner test duration varies significantly (25–60+ minutes).
  Deterministic sharding is planned as a separate reliability improvement.
- `slow-shard-2` contains capability-sensitive native-security tests that
  may produce explicit skips on hosted runners lacking specific kernel
  features or privileges.
- The Governed Research Workspace product proof is not shipped in this
  release.

## Upgrade notes

- Provenance-version-1 payloads now require complete provenance fields.
  Incomplete current-version records fail closed — update producers
  to emit complete provenance.
- Legacy (version 0) and pre-version payloads remain supported unchanged.
- No breaking API changes.
