# Support

## How to get help

| Need | Channel |
|------|---------|
| Bug report | [Open a GitHub issue](https://github.com/Alajmah/NodeChain/issues) |
| Feature request | [Open a GitHub issue](https://github.com/Alajmah/NodeChain/issues) (feature requests do not imply acceptance) |
| Security vulnerability | Use **GitHub private vulnerability reporting** (Security tab → "Report a vulnerability"). **Do not** open a public issue. |
| Question about usage | [GitHub Discussions](https://github.com/Alajmah/NodeChain/discussions) (if enabled) or an issue with the `question` label |

## Before reporting a bug

1. Search existing [issues](https://github.com/Alajmah/NodeChain/issues) to avoid duplicates.
2. Reproduce the issue on the latest `master`.
3. Include:
   - NodeChain version (`nodechain --version`)
   - Python version (`python --version`)
   - Operating system and version
   - Minimal reproduction steps
   - Expected vs. actual behavior

## Security issues

Security vulnerabilities must **not** be reported via public issues. See
[SECURITY.md](SECURITY.md) for the responsible disclosure process.

## Project status

NodeChain is under active, roadmap-controlled development. Not all features
documented in the roadmap are implemented yet. See the project documentation
and CHANGELOG for current capabilities.
